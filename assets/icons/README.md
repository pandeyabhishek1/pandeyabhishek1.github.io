# Contact icons

Local SVG assets used by the contact section in index.html.

- email.svg, linkedin.svg, github.svg: Bootstrap Icons v1.11.3, MIT license. Source: https://github.com/twbs/icons/tree/v1.11.3/icons
- google-scholar.svg: Simple Icons v15.0.0, CC0-1.0. Source: https://github.com/simple-icons/simple-icons/blob/15.0.0/icons/googlescholar.svg

All contact links currently use ./ (the website home page), as requested. Replace the four href attributes in the contact section with your mailto: address and profile URLs when available. Brand names and logos remain subject to their owners' trademark guidelines.
